# 📰 Записки Деда — Mini App, выпуск №23

Это первый прототип интерактивной газеты на основе вашего выпуска №23.

## Файлы
- `index.html` — интерфейс
- `style.css` — оформление
- `app.js` — интерактивность
- `gazeta23.jpg` — исходная газета

## Публикация на GitHub Pages
1. Создайте публичный репозиторий `gazeta-deda`.
2. Загрузите все 4 файла из этой папки в корень репозитория.
3. GitHub → Settings → Pages.
4. Source: Deploy from a branch.
5. Branch: `main`, folder: `/ (root)`.
6. Save.
7. GitHub выдаст HTTPS-адрес страницы.

После этого страницу можно будет подключить к Telegram-боту как Mini App.

## Что уже работает
- адаптация под телефон;
- интерактивные зоны поверх газеты;
- открытие рубрик;
- реакции;
- кнопка поделиться;
- нижняя навигация;
- подготовка к запуску внутри Telegram.
